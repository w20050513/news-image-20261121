"WORLD IN A DAY" - a dark news-dashboard poster that sums up the world news
of Saturday 21 November 2026 in a single 1024x1024 image: NATO's vow to
defend Poland after Russian missiles crossed its border, Iran's rejected
bid for talks, the missiles intercepted over Riyadh, Trump's message to
Europe on Ukraine funding, the COP31 deadlock in Antalya, Wall Street's
AI reality check, the claimed proof of the Riemann hypothesis, the Geneva
killer-robot talks and the magnitude 6.8 Peru earthquake, plus a wire
strip of shorter items. The picture is drawn entirely by the program
itself - a small pure-stdlib stroke renderer with its own typeface and
PNG writer - so the output is deterministic, byte for byte.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
